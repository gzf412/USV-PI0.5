# 输入与动作协议

架构采用π0.5；33维状态经固定尺度归一化后编码为语言前缀，动作专家输出`[H,2]`连续推力。当前H=10，初次部署计划每次执行1步并重新观察，实际模型推理速度仍待验证。

前9维依次为：前向对地速度u、左向对地速度v、船体z轴角速度r、横滚、俯仰、相对回合初始航向的sin/cos、上一条已发布左右指令各除以15N。

后24维为8个固定槽位，每槽`[前向米, 左向米, present]`。顺序：红圆、红尖、黄圆、黄尖、绿圆、绿尖、蓝圆、蓝尖。每种颜色和形状组合最多一个。缺失填`[0,0,0]`，已知且定位有效的镜头外浮标保留位置和present=1；后方目标允许前向分量为负。槽位不随距离重新排序。

相对坐标根据统一局部ENU位置和艇的ENU航向计算，不能用回合相对航向直接替代坐标旋转。当前采集是显式标注的模拟器位姿调试源；u/v来自因果后向差分，角速度来自IMU。GPS/IMU原始数据保存，实艇定位融合尚未实现。

图像预留3路RGB，当前只有前向；另外两路填黑且image_mask=false。原始1280×720，模型带填边缩放到224×224。LeRobot返回CHW浮点图，适配器转换为RGB uint8；实时输入可直接给HWC uint8。

采集还默认启动一个独立空中俯视相机，用于生成`videa/aerial_global.mp4`检查回放。它不进入策略的SensorStore，不占用上述3路模型图像槽位，导出训练集仍只读取前向`images/`与决策记录。详细时间轴与原始文件见`docs/videos.md`。

归一化：u/v除以2m/s，r除以1rad/s，roll/pitch除以pi，相对位置除以32米，sin/cos和存在标记不变。上一指令已在记录时归一化，避免再次除以15。当前π0.5位置量化档约0.25米，超范围拒绝，不静默饱和；文本上限384，超长报错。

动作固定顺序`[left_thrust_N,right_thrust_N]`，记录已发布、限幅到每侧±15N的指令，不表示测得的真实推力。模型训练输入动作除以15N，模型输出检查两维、有限值、限幅后恢复牛顿。

结构化字段见`configs/observation.json`，实现分别在`src/usv_vla/core.py`与`src/openpi/policies/usv_policy.py`。

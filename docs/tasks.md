# 当前简单任务

1. 驶近指定颜色和形状的浮标并停下。
2. 从指定浮标左侧或右侧通过，在退出区域停下。
3. 从A指定侧通过，再驶近B并停下。

左右侧依据通过阶段起点指向A的水平接近方向定义，并保持冻结，不能随相机或当前船头方向改变。任务管理器把原始完整指令、当前阶段和冻结参照送进模型可见上下文。通过阶段由已发生轨迹的因果判据推进，不从未来成功标签反推。

当前接近验收：船中心距目标中心1.9～2.3米，速度≤0.2m/s持续2秒；任一条件中断重新计时。规则控制器瞄准2.1米中心距。另检查碰撞、保守扫掠净距、越界和120秒超时。红圆浮标按0.75米半径、艇按0.85米包围半径检查，1.9米中心距对应0.3米保守净距，仍高于0.2米限制。归零推力不等于船已停稳。

指定侧通过示例：设接近方向为x正、左侧为y正，A为局部原点。左门为x=0、y在[2,4]米，退出区域为x在[2,4]、y在[2,4]；右侧对应y在[-4,-2]。必须从x负侧正确穿门，再进入退出区；仅到浮标旁边不算通过。通过线按相邻轨迹段插值，不要求恰好采到线上的一帧。首次从错误门通过判失败。

组合任务先正确过A，再满足B的接近停止条件。镜头外已知目标使用相对位置引导转向，任务验收不依赖它是否在画面中。初始参数已在简化动态艇试跑，实艇仍须标定。当前不采绕完整一圈或任意长任务序列。

规则控制器仅用于链路验证和示范生成，不能当作训练后的π0.5效果。人工演示质量与训练后闭环仍待验证。
